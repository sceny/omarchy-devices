# Assets and the tests that hold them

[Back to the README](../../README.md) · [Security and privacy](../security.md)

Each asset the threat model protects, with the tests that fail the build when
it is exposed. *Held by* names a test file and its classes (`file` `Class`,
`test_name` in brackets for one test, *italics* for a JS test's title).
*Manual* is what no script can hold, and why. *Gap* is a way the asset leaks
that no test holds, with the issue that adds the test; a gap that is an
unfixed fault shows as `pending: tracked privately` until the fix is released.

`tests/test_asset_tests.py` fails when a row has neither a test nor a
`manual:` line, when it names a file, class, test or title that does not exist,
and when a gap has neither an issue nor the pending mark.
