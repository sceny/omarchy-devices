# Set up Contacts

Once per phone. The phone sends its address book to this computer; the
[Contacts page](../use/contacts.md) reads it, and
[Messages](../use/messages.md) and [Calls](../use/calls.md) take their names
from it.

Nothing is set up ahead. The first time you open **Contacts**,
the page asks for what is missing, and goes on by itself when it is done
(Messages never asks for it, and searching a new message by name offers the
same *Allow*):

1. **Contacts** switched on for this phone (*What it shares with this
   computer*, on its page). The panel turns it on for you.
2. **The phone's permission to read contacts** for KDE Connect, once. With
   the screen set up, *Allow* grants it from here; otherwise the page names
   the one step on the phone (KDE Connect › Permissions › contacts).

The phone then sends its cards when the panel opens on the page, at most
every five minutes; `r` asks again. A page with no cards says that the phone
has none yet, or that it has not allowed contacts, never that something
broke.

Not wanted? Its switch on the device's page turns it off: texts show
numbers, and nothing about it is a problem.

## When it stops working

- *No contacts yet*: the phone has not allowed contacts to KDE Connect, or
  the switch is off. *Fix* does what it can, or says the tap left to you.
- A name is missing in a conversation: that number has no card on the phone.
- An iPhone sends no contacts at all.

Limits: [What it cannot do](limits.md#contacts)
