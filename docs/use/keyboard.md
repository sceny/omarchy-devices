# The keyboard

Everything in the panel is a key away, with one cursor that glides from
row to row. Nothing but your own click or Enter ever puts it in a text
field, so a stray keystroke never becomes a sent text.

| Key | Action |
|---|---|
| `j` `k` / arrows · PgUp PgDn · `g` `G` | Move · a page · first, last |
| `h` `l` | Sideways: shortcuts, players, into a conversation, open · fold a stack of notifications |
| Enter or Space · Shift+Enter | Activate · an app popped out |
| Tab · Shift+Tab | The next · previous panel in the bar |
| Esc · `0` | Back to where you came from, one step at a time; then close · Home (the main page, from two pages deep) |
| `c` | Fold the section under the cursor |
| `r` · `x` · `e` · `o` | Reply · dismiss (a notification, a stack on its title, or a received file) · show all · open its app |
| `Shift+Delete` | Dismiss all notifications (cursor in Notifications) |
| `[` `]` · `,` `.` · `-` `=` | Skip · seek 10 s · volume |
| `m` · `a` · `s` · `E` | Messages · all apps · Settings · edit the page |
| `/` · `u` · `n` · `i` · `p` | Search · unread · new message · reply · pin |
| `v` | Where an open app's sound plays |
| `r` | Refresh (Contacts) |
| `1`–`9` · `Shift+H` `Shift+L` | Switch device · previous · next device, or move a pinned app |
| `Shift+K` `Shift+J` | Move a section, a device, a shortcut · with the Keys list open, its previous · next group |
| `Shift+O` | With the Keys list open, go to the group's place |
| `?` | Keys: every key, over the page you are on |

Esc and the back arrow go back to where you came from: from a text started
on a contact, to that contact. Home shows once you are two pages deep, left
of the back arrow.

`?` lists them over the page you are on, with the group for where you are
unfolded; the right-click menu and the last row in Settings open it too. The
page keeps its keys, so you can try one with the list open. Each group's
**Open** (or `Shift+O`) goes to that page or section, closes the list and
marks the place for a moment. `?` or Esc closes it.

Each page lists its own: [The panel](panel.md), [Messages](messages.md),
[Apps](apps.md), [Make it yours](edit.md).
